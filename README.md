# Arztbriefgenerator

Lokaler, statischer Arztbriefgenerator für strukturierte kardiologische Arztbriefe.

## Start
Einfach `index.html` im Browser öffnen.

## Enthalten
- Moderne lokale Weboberfläche
- Ausgabe in 3 Feldern: Aktuelle Diagnosen, Epikrise, Procedere
- Fallgruppen:
  - ACS mit PCI
  - Device (PM/ICD/CRT-P/CRT-D/LifeVest)
  - Klappenvitien (TAVI/M-TEER/T-TEER/OP)
  - Lungenarterienembolie (mit optionaler Thrombektomie)
- Synonymvariation bei Formulierungen
- Feldmatrix als Grundlage zur Erweiterung in `FELDMATRIX_V1_1.md`
